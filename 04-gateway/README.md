# 04 · 服务端：让模型知道这是视频通话

app 做得再好，模型不知道「现在在打视频、看得见还是看不见」，ta 就会用聊天腔回你，或者对着一张旧图说话。
这一章的坑全是静默的：没有报错，只是 ta 的语气不对。

## 1. 每一轮要告诉模型什么

app 发上来的每条消息带前缀，例如 `[视频通话·…]`。网关看到前缀就给模型加一段通话规矩：

- 短句、口语，像说话不像发消息；只说一种语言、不要翻译。
- 你的画面是她的前置**或后置**摄像头 —— 后置拍的不是她的脸。
- 可以写的标记：`〔表情〕`（换照片，见 02）、`（动作）`（上屏不念）、`⟪看一眼⟫`（见 01）、接通时想先等她就只回 `⟪等她⟫`。
- **这一轮看不看得见**，明写出来（见坑 4.4）。

## 2. 图从哪来、给几张

- 视频轮次的图**只从这一条用户消息里取**，历史帧不重发。
- 视频轮单独给图片预算，别跟聊天共用一个「最多 2 张」。

## 3. 出口的兜底

模型不一定每次都听。出口再拆一遍：

- 擦掉通话里不该出现的外壳（比如聊天里的语音气泡格式）和情绪标签，TTS 不认识它们。
- 一轮里既有英文段又有中文段 → 丢掉中文行（防「说一遍再翻译一遍」）。

## 这一章的坑

### 4.1 网关只认「语音通话」✅
- **现象**：视频里 ta 用聊天腔回 —— 中文长段、省略号、多行。
- **根因**：判断「是不是在打电话」的正则只写了 `[语音通话`。视频里整套通话规矩从第一天起就没发过。
- **修法**：`(语音|视频)通话`，再加一段视频专属说明。
- **取证**：把每轮真实发给模型的 system 打出来看，别看你以为发了什么。

### 4.2 带图那一轮判据又失效 ✅
- **根因**：判据只看 `content` 是字符串的情况。一开镜头，`content` 变成 `[{text},{image}]` 数组，判据返回假。**开镜头的每一轮必中**，视频模式实际一次都没生效。
- **修法**：先把数组里的 text 块拼出来再匹配。

### 4.3 第二条模型线压根没收到规矩 ✅
- **现象**：走 A 线一切正常；走 B 线（一个常驻的长会话进程），ta 回的是语音气泡外壳加标签，你一个字都听不到。
- **根因**：通话规矩只拼进了 A 线的 system。B 线只往会话里追加最后一条用户消息。
- **修法**：B 线通话第一轮把整份规矩贴进用户消息，之后每轮贴一句短提醒；出口加兜底。
- **教训**：有几条线就在几条线上分别验。

### 4.4 镜头关着，ta 说「我看到你了」🟡
- **根因**：没帧那一轮什么都不标。前几轮的图还在历史里，前缀又写着视频通话，模型以为自己看得见。「没图就是关了镜头」这种规则要模型从缺失里推，推不住。
- **修法**：没图时明写，分三种：还没选镜头 / 关着 / 开着但这轮没取到。接通、她说话、ta 看一眼、沉默接话四个入口都标。
- **原则**：别让模型从「没有」里推断。缺什么就写缺什么。

### 4.5 第一轮混进了别的图 ✅
- **现象**：刚接通还没开镜头，ta 说她「脸上有枕头印」。
- **根因**：按「最近 N 条消息里的图」取，捞到了几分钟前聊天里的一张配图。

### 4.6 只放进最前面两张 ✅
- **根因**：全局图片预算 2，超出的退成文字，留的还是**最前两张** —— 她说完那一刻那张从没被看见。

### 4.7 通话里 ta 回拨，把她那通顶掉了 ✅
- **根因**：记忆召回按关键词，「视频」把「怎么给她打电话」的规则捞进来，ta 第一轮就写了拨号标记。
- **修法**：通话中不召回拨号规则；通话轮次里的拨号标记只擦不拨。

### 4.8 后台自主活动在通话中弹了张卡 ✅
- ta 的后台活动开始前查过她不在通话，动手那刻没再查。**闸要拦在动手那一刻**，不是计划那一刻。
