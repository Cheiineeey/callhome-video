## 2. 光：跟着声音呼吸

```swift
// 音量来自本地播放器
player.isMeteringEnabled = true
player.updateMeters()
var level = (player.averagePower(forChannel: 0) + 50) / 50   // dB → 0…1
level = max(0, level) * max(0, level)                        // 平方：小声更安静
smoothed = smoothed * 0.7 + level * 0.3                      // 低通，不抖

let breath = sin(t * 2 * .pi / 5)                            // 5 秒一个呼吸
let scale = 1 + 0.10 * breath + 0.55 * smoothed
```

关键是：**声音必须从本地播放器出**，光才有东西可读。实时档也遵守这一条（见 03），所以三档共用一个声源。

## 3. 照片：ta 自己挑脸

准备几张同一个人、同一套光线的照片：看着你 / 笑 / 不高兴 / 撑着头……
ta 在一轮开头写一个标签，比如 `〔笑〕`，app 摘掉标签、换图、淡入 0.5 秒。没写标签就用「看着你」那张。

换脸的完整规则：

- **每轮开始先回到「看着你」。** 上一轮笑完，这一轮没写标签就不该还笑着。
- 一轮里只在出现标签的那一刻换。流式输出时，标签一闭合就换，不等整轮写完。
- 跟当前同一张就不动，不重放淡入。
- 不认识的标签直接吞掉，不上字幕也不念。
- 挂断、新一通开始都清回默认。
- 实时档底下垫的那张要跟数字人的源图是同一张，不然一停下来就「变回照片」（03 坑）。

- 标签表**两边要一起改**：app 里的映射表、服务端告诉模型有哪些标签的那句话。
- 别在说话时自动切「说话脸」—— 句间会来回淡，一轮闪好几次。只在 ta 写了标签时换。
- 照片我们用 AI 生成，同一张参考图出一组，脸才是同一个人。

## 4. 动作行：上屏不念

ta 可以在开头写一句全角括号的动作，比如 `（撑着下巴看你）`，显示在画面上，**不进语音合成**。

- 摘括号时，**没闭合的半截也要藏**。流式输出时先到「（低头」，不藏的话 TTS 会念出来。
- 新一轮清空上一轮的动作。

## 5. FaceTime 式布局

- 默认满屏是 ta，你在右上小窗；点小窗对调，拖动吸附四角。
- **一个相机会话只挂一个预览层**。对调是改同一个 view 的尺寸，不是建两个。
- 视频通话不开接近传感器（不然脸一靠近屏幕就黑），开 `isIdleTimerDisabled`，挂断复位。

## 这一章的坑

### 2.1 一开相机，声音跑去听筒 ✅
- **现象**：字一句句出来，听不到声音。服务器日志显示一段播完才拉下一段 —— 播放器以为自己在放。
- **根因**：`AVCaptureSession.automaticallyConfiguresApplicationAudioSession` 默认是 `true`。开相机时它重配了音频会话，把 `.defaultToSpeaker` 冲掉了。语音通话有接近传感器那条兜底会切回外放，视频不开接近传感器，没人管。
- **修法**：
  ```swift
  captureSession.automaticallyConfiguresApplicationAudioSession = false
  // 开相机之后、视频接通时，再显式钉一次外放
  ```

### 2.2 字幕露出了内部标记 ✅
- **根因**：字幕改成显示整段之后，用的是没擦过标记的原文（以前只显示正在念的那句，那句擦过）。
- **修法**：上屏前统一过一遍擦标记的函数。所有新加的显示入口都要过。

### 2.3 照片换得太勤 ✅
- **现象**：一轮里照片来回淡好几次。
- **根因**：说话时自动切「说话脸」，句与句之间的空隙又淡回「看着你」。
- **修法**：去掉自动切换，只有 ta 自己写了标签才换（见第 3 节）。
